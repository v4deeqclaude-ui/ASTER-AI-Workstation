# Tests

Автоматизированный тестовый проект будет добавлен после стабилизации первой сборки на Windows.

Ручная проверка версии 0.1:

1. Запустить приложение.
2. Добавить временную папку тестового проекта.
3. Убедиться, что папка и файлы отображаются.
4. Закрыть приложение и открыть снова — запись проекта должна сохраниться.
5. Создать резервную копию базы.
6. Убрать проект из списка и убедиться, что папка на диске осталась.
