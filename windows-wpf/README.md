# ASTER AI Workstation 0.1

Первая локальная версия Windows-приложения ASTER AI Workstation.

## Что реализовано в 0.1

- Минималистичное WPF-окно на русском языке.
- Добавление существующих папок проектов через диалог Windows.
- Сохранение списка проектов в SQLite.
- Переключение между проектами.
- Просмотр верхних уровней папок и файлов в режиме только чтения.
- Удаление записи проекта из списка без удаления файлов на диске.
- Создание резервной копии локальной базы данных.
- Раздельные проекты Core, Data, Projects и App.

## Что пока не реализовано

- OpenAI API и AI-чат.
- Подключение и управление Unity / Blender.
- Управление окнами мышью и клавиатурой.
- Облачная синхронизация и облачные резервные копии.
- Установщик MSI/EXE.

Эти функции предусмотрены архитектурой и будут добавляться отдельными этапами. В версии 0.1 API-ключ не нужен.

## Требования

- Windows 11 x64.
- .NET 10 SDK (для запуска из исходников).
- Интернет при первом восстановлении NuGet-пакетов.

## Запуск

1. Распакуй архив в отдельную папку, например `C:\ASTER-AI-Workstation`.
2. Установи .NET 10 SDK, если он ещё не установлен.
3. Открой PowerShell в папке проекта.
4. Выполни:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Run-ASTER.ps1
```

Или запусти вручную:

```powershell
dotnet restore .\ASTER.Workstation.sln
dotnet run --project .\src\ASTER.Workstation.App\ASTER.Workstation.App.csproj
```

## Локальные данные

Приложение хранит данные отдельно от исходников проекта:

`%LOCALAPPDATA%\ASTER\Workstation\`

- `Database\aster-workstation.db` — база проектов и настроек.
- `Backups\` — резервные копии базы.
- `Settings\` — место для будущих локальных настроек.

## GitHub

Создай отдельный репозиторий `ASTER-AI-Workstation` и загрузи в него содержимое этой папки. Не добавляй в репозиторий API-ключи, личные настройки или папку локальных данных приложения.

Пример первой отправки из PowerShell:

```powershell
git init
git add .
git commit -m "ASTER AI Workstation 0.1 - initial Windows shell"
git branch -M main
git remote add origin https://github.com/ВАШ_АККАУНТ/ASTER-AI-Workstation.git
git push -u origin main
```

Перед `git push` замени адрес remote на адрес своего репозитория.

## Безопасность версии 0.1

- Добавление проекта только регистрирует выбранный путь.
- Обзор файлов не изменяет содержимое проекта.
- Удаление проекта удаляет только запись из базы ASTER; исходная папка остаётся на диске.
- Программа не запускает Unity, Blender, PowerShell-команды или сторонние процессы.
- Никакие API-ключи не запрашиваются и не сохраняются.

## Отправка WPF-версии в существующий GitHub-репозиторий

В репозитории уже есть Electron-прототип. Чтобы не смешивать технологии и не перезаписывать его файлы, WPF-основа отправляется в отдельную ветку `feature/wpf-foundation-0.1` и в каталог `windows-wpf/`.

После распаковки архива запусти в PowerShell:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Publish-WPF-To-GitHub.ps1
```

Скрипт клонирует репозиторий в отдельную папку профиля пользователя, создаёт ветку и подготовит файлы. Отправка произойдёт только после того, как ты введёшь `PUSH`.
