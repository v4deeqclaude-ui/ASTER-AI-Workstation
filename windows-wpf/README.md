# ASTER AI Workstation — локальная версия

ASTER — Windows-приложение с рабочим пространством проектов и встроенным AI-чатом. На этом этапе чат работает только с локальной моделью через Ollama. Подключение к ChatGPT и OpenAI API в этой версии отсутствует.

## Что реализовано

- Русскоязычный WPF-интерфейс.
- Встроенный чат в центральной рабочей области ASTER.
- Подключение локальной модели через Ollama.
- Настройка адреса Ollama и имени модели.
- Проверка доступности локального сервера и установленных моделей.
- Сохранение истории переписки в локальной базе SQLite.
- Добавление существующих папок проектов и просмотр структуры файлов.
- Резервное копирование локальной базы данных.

## Локальный ИИ

По умолчанию используются:
- Адрес: `http://localhost:11434`
- Модель: `qwen3:1.7b`

Установи и запусти Ollama, затем убедись, что модель загружена. В ASTER открой «Настройки» → «Проверить Ollama». Для локальной модели не нужен API-ключ и не требуется вход в аккаунт.

## Требования

- Windows 11 x64.
- Ollama для работы AI-чата.
- .NET 10 SDK только для запуска из исходников.
- Интернет при первом восстановлении NuGet-пакетов.

## Запуск из исходников

Из папки `windows-wpf`:

```powershell
dotnet restore .\ASTER.Workstation.sln
dotnet run --project .\src\ASTER.Workstation.App\ASTER.Workstation.App.csproj
```

## Локальные данные

Данные хранятся отдельно от исходников:

`%LOCALAPPDATA%\ASTER\Workstation\`

- `Database\aster-workstation.db` — проекты и история AI-чата.
- `Backups\` — резервные копии базы.
- `Settings\ai-provider.json` — адрес сервера и имя модели Ollama.

Удаление или обновление файлов приложения не должно затрагивать эту папку данных.

## Текущие ограничения

- В этой версии поддерживается только Ollama.
- Подключение ChatGPT и OpenAI API намеренно исключено; при необходимости его можно будет разработать отдельным этапом.
- Интеграции Unity, Blender и других программ будут добавляться отдельно.
