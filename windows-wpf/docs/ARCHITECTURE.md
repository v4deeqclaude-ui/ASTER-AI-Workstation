# Архитектура ASTER AI Workstation

## Слои

- `ASTER.Workstation.App` — WPF-интерфейс, встроенный чат и клиент Ollama.
- `ASTER.Workstation.Core` — модели, интерфейсы репозиториев и общие пути приложения.
- `ASTER.Workstation.Data` — SQLite и реализация хранения.
- `ASTER.Workstation.Projects` — обзор файловой структуры проектов.

## AI-архитектура текущей версии

На этом этапе используется только локальный Ollama API:
- проверка сервера через `GET /api/tags`;
- отправка диалога через `POST /api/chat`;
- адрес и модель хранятся в `Settings/ai-provider.json`;
- история сообщений хранится в локальной SQLite базе.

ChatGPT OAuth, OpenAI API, сетевой прокси и облачные AI-провайдеры в текущую сборку не входят. Их можно будет добавить позднее как отдельные необязательные модули.

## Принципы

1. Рабочие проекты пользователя не копируются и не перемещаются при добавлении.
2. Файловый обзор работает только на чтение.
3. Удаление записи проекта не удаляет папку на диске.
4. Локальные данные приложения отделены от каталога с исходным кодом.
5. AI-чат обращается к локальному серверу Ollama.
6. Доступ AI к файловой системе проекта не предоставляется автоматически.
