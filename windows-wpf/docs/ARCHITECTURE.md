# Архитектура ASTER AI Workstation 0.1

## Слои

- `ASTER.Workstation.App` — WPF-интерфейс и пользовательские сценарии.
- `ASTER.Workstation.Core` — модели, интерфейсы репозиториев и общие пути приложения.
- `ASTER.Workstation.Data` — SQLite и реализация хранения.
- `ASTER.Workstation.Projects` — обзор файловой структуры проектов.

## Принципы

1. Рабочие проекты пользователя не копируются и не перемещаются при добавлении.
2. В версии 0.1 файловый обзор работает только на чтение.
3. Удаление записи проекта не удаляет папку на диске.
4. Локальные данные приложения отделены от каталога с исходным кодом.
5. Будущие интеграции Unity, Blender и других приложений должны реализовывать отдельные адаптеры.
6. AI-агент не получает произвольный доступ к файловой системе: доступ будет ограничиваться разрешёнными корнями проекта и отдельными операциями.
