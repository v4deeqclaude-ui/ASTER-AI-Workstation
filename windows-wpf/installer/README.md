# Установка

В версии 0.1 полноценный MSI/EXE-установщик ещё не включён.

Для получения автономной папки приложения запусти из PowerShell:

```powershell
.\scripts\Build-Release.ps1
```

Результат появится в `publish\win-x64`. На целевом компьютере .NET Runtime для запуска этой опубликованной сборки не потребуется. Для сборки нужен .NET 10 SDK.
