# ASTER AI Workstation

Русскоязычное настольное AI-приложение для Windows.

## Запуск
Требуется Node.js 20 LTS или новее:
```powershell
npm install
npm start
```

## Сборка установщика
```powershell
npm run dist:win
```
Инсталлятор появится в папке `release`. GitHub Actions также собирает Windows-установщик вручную (Actions → Build Windows installer) и при публикации тега вида `v0.1.0`.

## Возможности этапа 0.1
- Русский тёмный интерфейс.
- Чат с локальной историей.
- OpenAI-compatible Chat Completions API.
- Хранение API-ключа через Electron safeStorage, если доступно.
- Добавление и запуск локальных EXE-программ.

Облачные аккаунты, синхронизация, полноценные MCP-инструменты, плагины и управление Unity/Blender из чата пока не реализованы и относятся к следующим этапам. API-запросы оплачиваются выбранному провайдеру отдельно. Не публикуйте API-ключи в репозитории.
